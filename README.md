# 근무시간 계산기

[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](LICENSE)

단일 HTML 파일 (`app\index.html`) — 설치 불필요.
**권장 실행법**: 최상위 `근무시간 계산기.bat` 더블클릭 → 서버 기동 + 페이지가 `http://127.0.0.1:8737/`로 자동 열림.
(`index.html`을 직접 더블클릭(file://)해도 동작은 하지만, 토스트/자동백업/스냅샷 등 서버 기능은 사용 불가)

## 폴더 구조
```
calc_working_time\
├─ 근무시간 계산기.bat      ← 실행은 이 BAT 파일만 (더블클릭)
└─ app\
   ├─ index.html            앱 본문
   ├─ toast_server.ps1      서버 (BAT가 호출: 토스트/서빙/백업/스냅샷/바로가기)
   ├─ app.ico               앱 아이콘 (바로가기용)
   ├─ backup_auto.txt       자동 백업 미러 (공유 저장소)
   ├─ backups\              수동 백업 파일 저장 위치 (근무시간백업_YYYYMMDD_HHMM.txt)
   ├─ snapshot\             일일 스냅샷 (backup_YYYY-MM-DD.txt, 30일 보관)
   ├─ toast_server.log      서버 로그
   ├─ make_shortcut.ps1     바탕화면 바로가기 생성 스크립트
   ├─ check_shortcut.ps1    바로가기 설정 확인 스크립트 (검사용)
   ├─ folder_report.ps1     폴더 점검 리포트 스크립트 (→ folder_report.txt)
   └─ README.md             이 문서
```
BAT 하나만 최상위에 있습니다. 앱 파일은 모두 `app\` 하위에 있습니다.

## 사용법
- **월 선택**: `◀` / `▶` 버튼 또는 달력 아이콘으로 선택 → 해당 월 달력 표시
- **요약 카드**: `의무`(자동 계산값/직접 입력) · `근무`(이번 달 합계) · `잔여`(근무−의무)
  - 잔여는 문구 없이 숫자만: 부족 `−40시간`(빨강) / 초과 `+60시간`(초록) / 일치 `0`(초록)
- **의무근무시간 자동 계산**: `min(워킹데이×8, floor(역일÷7×40))` — 소수점 버림
  - 워킹데이 = 월~금 평일 수, **화면에서 휴일 지정/해제 시 즉시 재계산** (근무 합계·잔여도 함께 갱신)
  - 입력칸을 **비우면 자동값 사용** (플레이스홀더에 `자동: 176` 표시), 직접 입력하면 그 값 우선
  - **계산값과 동일한 값을 입력하면 저장되지 않고 자동 모드 유지** — 매번(월 이동·휴일 변경 시) 새로 계산된 값 표시
  - **계산값과 다른 값만 저장** — 월 이동 후에도 그 값 유지
- **일별 근무시간**: 평일 셀의 **시/분 입력란 2개**(라벨 없음, 붙어 있음)에 직접 입력 (예: `8` / `30`)
  - **시작/종료 시간을 입력한 날은 그 셀의 시/분 직접 입력이 비활성화**됨 (모달의 `시간 삭제`로 초기화하면 다시 입력 가능)
  - 분은 **59 초과 입력 시 자동 59**, 시는 **24 초과 입력 시 자동 24**로 보정
- **시작/종료 시간 입력**: 셀 하단의 `⏱ 시간 입력`(또는 `09:00–18:00` 같은 시간 표시) 클릭 → 팝업 모달
  - 시간은 **24시 기준 키보드 직접 입력** (AM/PM 없음)
  - 콜론 없이도 인식: `930` → 09:30, `1805` → 18:05, `9` → 09:00
  - **제외(휴게) 시간**: 4시간 미만 → 0분, 4시간 이상 9시간 미만 → 30분, 9시간 이상 → 60분이 **자동 제안**되며,
    팝업의 `제외 시간(분)` 칸에서 **직접 수정 가능** (수정값은 모달을 다시 열어도 유지)
  - 종료 < 시작 이면 **익일(야간) 근무**로 계산 (예: 21:00–06:00 = 9시간 − 휴게)
  - 입력한 시작/종료/제외 시간은 모달을 다시 열면 그대로 유지됩니다
- **최초 미입력 월**: 평일이 자동으로 **8시간**씩 채워진 상태로 시작
- **휴일 지정/해제**: 평일 셀을 **더블클릭**
  → 셀이 **빨간 배경 + `휴일` 배지**로 변하고, 입력된 시간은 **제거**되며, 합계에서 제외
- **토/일**: 달력 화면에 **표시되지 않음** (월~금 5열, 합계에서도 제외)
- **백업**: 화면 **최하단** `백업` 버튼 → 경로 지정 창 → `.txt` 파일로 **전체 누적 월 데이터 1회 저장**
  (저장 위치로 `app\backups\` 권장 — 수동 백업 파일은 이 폴더에 모아 관리)
- **복구**: 화면 **최하단** `복구` 버튼 → 경로 지정 창 → 백업 `.txt` 선택 → **전체 월 데이터 일괄 교체**
- **예상시간**: 상단 `예상시간` 버튼 → 미리보기 계산기 (일별 `⏱ 시간 입력`과 동일한 계산 규칙:
  24시 시작/종료, 휴게 자동 제안·수정, 익일/야간). **저장되지 않음** — 닫으면 사라지는 계산 전용
- **도움말**: 상단 `도움말` 버튼 → 이 README.md를 화면 모달로 표시.
  서버가 **클릭 시점에 README.md를 디스크에서 직접 읽으므로**, 파일 수정 후 도움말을 다시 열면 즉시 반영 (사본 아님, 캐시 없음)

## 저장 / 백업 계층 (3겹)
| 계층 | 위치 | 갱신 | 용도 |
|---|---|---|---|
| 자동 저장 | 브라우저 `localStorage` | 모든 입력 즉시 | 작업 사본 (원본) |
| 자동 백업 미러 | `app\backup_auto.txt` | 모든 입력 즉시 (서버 켜질 때) | 최신 사본 1개 — 브라우저 교체/공유용 |
| 일일 스냅샷 | `app\snapshot\backup_날짜.txt` | **그날 최초 저장 1회** | 시간 캡슐 — 30일 보관, 날짜 골라 되돌리기 |

- **브라우저/주소 공유 동기화**: 페이지 열기 시 + **60초마다** 서버의 `backup_auto.txt`를 읽어와
  **저장 시각이 더 최신이면 자동 반영** → Chrome/Edge, `file://`/`http://127.0.0.1:8737/`
  어느 쪽에서 작업해도 최신 데이터로 통일 (반영 시 하단 안내 표시)
  단, 서버 꺼진 동안의 작업은 미러되지 않음
- **스냅샷에서 복구**: 화면 **최하단** `스냅샷 선택…` 드롭다운 + `스냅샷 복구` 버튼 (서버 실행 시 표시).
  날짜를 골라 확인 후 그 시점 상태로 되돌린다. 스냅샷 생성 시 Windows 토스트 알림
- **하단 상태 표시**: `최종 저장` · `서버 동기화: HH:MM:SS (최신 반영)` · 저장된 월 개수
- **동시 접속 경고**: 최근 45초 내 접속한 다른 브라우저/탭이 있으면 하단 빨간 표시
  `⚠ 다른 브라우저/탭에서 열려 있음 (N개)` — **클릭 시 열린 탭 목록 상세**, 목록 행 클릭 시 해당 창 최전면
  (자기 탭은 세지 않음. 탭 종료 시 즉시 제거, 브라우저 창 전체 종료 시 최대 45초 후 소멸)
- **바로가기 생성**: 화면 **최하단** `바로가기 생성` 버튼 → 바탕화면에 `근무시간 계산기.lnk`
  생성 (app.ico 아이콘). BAT를 쓸 수 없는 환경(서버 자동 열기 탭 등)에서 유용

## 알림 (요약 카드 우측, 기본 접힘)
**알림은 1회성** — 발동하면 목록에서 자동 제거되고, **실행 이력**(언제 발동됐는지)만 화면에 표시됩니다.
두 가지 방식 중 선택해서 여러 개 추가 가능:
- **알림 메시지 입력**: 알림 섹션 최상단 입력란에 표시할 문구 입력 (예: "정시 퇴근하세요!")
  → 발동 시 팝업/토스트/이력에 그 문구가 표시됨. **비우면 `알림`으로 발동**
- **지정 시간**: 24시 기준 시각 입력 (예: `18:00`, `930` → 09:30) → 다음 도래 시점 1회 발동
- **경과 시간**: `N 시간 N 분` 입력 → 추가 시점부터 그 시간이 지나면 1회 발동
- 목록에 남은 시간 표시, `✕`로 삭제. 알림·이력 모두 자동 저장·백업/복구에 포함됨
- **알림 실행 이력**: `✔ 알림명 + 실행 시각` 최신 12건 표시, `이력 지우기` 버튼

### 발동 시 표시 (4중)
1. **Windows 우하단 토스트 (권장, 창 최소화 상태에서도 확실)** — BAT 실행 필요
   - **Python 불필요**: Windows 내장 PowerShell 5.1 전용 스크립트 (`toast_server.ps1`)
   - 페이지가 로컬 서버(127.0.0.1:8737)에 요청을 보내면 Windows 시스템 토스트로 표시
   - 사용법: `근무시간 계산기.bat` 더블클릭 → 서버 기동 + **페이지가 자동으로 `http://127.0.0.1:8737/` 열림**
     → 상태 문구 "토스트 실행자: 연결됨 ✓" 확인
   - **중요**: 반드시 `http://127.0.0.1:8737/` 주소로 열어야 합니다.
     `file://`로 열면 Chrome/Edge가 로컬 파일의 네트워크 요청을 차단해 토스트가 미발동
   - 서버는 상주 (서버 창을 닫으면 종료). 로그: `app\toast_server.log`
2. **별도 팝업 창 강제 표시** — 화면 중앙에 붉은 "⏰ 근무 알림" 창 (메인 창 최소화해도 뜸,
   최초 1회 팝업 차단 예외 허용 필요)
3. **Windows 우하단 시스템 알림** (브라우저 Notification 권한 허용 시)
4. 화면 하단 토스트 + beep 소리

- `테스트 알림` 버튼으로 즉시 확인 가능
- 창 최소화 상태에서 동작 (탭을 닫지 않는 한). 최소화/백그라운드 시 타이머가 1분 간격으로
  지연될 수 있어 **분 단위 정밀도** 발동
- Windows **집중 보조(Focus Assist)/게임 모드**가 켜져 있으면 시스템 알림이 알림 센터로만 갑니다
- 창을 닫으면 발동 불가 (설정·이력은 저장되어 다음 실행 시 복원)

## 저장 위치
`localStorage` 키 `calc_working_time_v1` — 브라우저+주소(origin)별로 분리 저장.
브라우저 캐시 삭제/PC 교체 시에는 백업 파일로 옮기세요.
서버가 켜져 있으면 `app\backup_auto.txt`가 브라우저 간 공유 저장소 역할을 합니다.

## 백업 파일 형식
UTF-8 텍스트(JSON):
`{ app, version, exportedAt, store: { months: { "2026-09": { required, days: { "2026-09-07": { hours, start, end, break, holiday } } } }, alarms, alarmLog, alarmOpen, savedAt } }`
수동 백업·`backup_auto.txt`·일일 스냅샷 모두 같은 형식 → 서로 `복구` 버튼으로 복원 가능.

## 서버 종료
- BAT로 연 서버 창(작업 표시줄 검은 창)을 닫으면 즉시 종료.
- **자동 종료**: 브라우저 탭이 90초 동안 아무 통신도 하지 않으면(탭을 모두 닫으면) 서버가 스스로 종료합니다.
  종료 직전 Windows 토스트로 "브라우저 연결이 없어 서버를 자동 종료합니다" 알림.
  탭이 열려 있는 동안(30초 heartbeat)에는 절대 종료되지 않습니다.
- 종료 후 페이지는 "토스트 실행자: 연결 안 됨"으로 전환되고 localStorage 저장은 계속 정상 동작합니다.

## 참고
- 백업/복구 경로 지정 창은 Chrome/Edge의 File System Access API 사용. 미지원 브라우저에서는
  다운로드 / 파일 선택 다이얼로그로 자동 폴백합니다.
- 휴일 지정은 평일 셀에서만 동작합니다 (주말은 원래 제외).
- 폴더 점검: `powershell -NoProfile -ExecutionPolicy Bypass -File app\folder_report.ps1`
  → `app\folder_report.txt`에 최상위/app 파일 목록, 구 파일 잔여 경고, BAT/필수 파일 확인, 스냅샷 목록 기록
